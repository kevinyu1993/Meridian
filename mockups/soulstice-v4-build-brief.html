4. Step-by-step Squarespace 7.1 build

Step 1 — Header (transparency + Patient Portal label)

Path: click anywhere on the header → Edit Site Header → Style tab.

  • Header background: Solid → 0% opacity (Transparent)
  • Text + icon color: White
  • Reduce header on scroll: ON
  • Branding tab → Logo on Image: upload white logo
  • Find the header button → relabel to Patient Portal → set URL → save

Step 2 — Replace the existing hero section

  • Open Home page in edit mode
  • Hover the first section under the header → gear icon → Delete Section
  • + Add Section → Banner template (or blank)

Step 3 — Section background image

  • Edit Section → Background tab → Image
  • Upload Kevin's sunrise photo, or use Squarespace's built-in Unsplash search (see Section 5)
  • Drag focal point to the warmest part of the sky

Step 4 — Color overlay

  • Same Background tab → Color Overlay → Enable
  • Color: Black #000000
  • Opacity: 45–55% (start at 50; adjust if text is hard to read)

Step 5 — Section dimensions

  • Width: Full width
  • Height: Large (or ~85vh)
  • Content Alignment: Center / Center (both axes)

Step 6 — Add content blocks (in order, all centered, all white)

  1. Text block for eyebrow → paste eyebrow copy → format as 12px Montserrat Medium, letter-spacing 3.5px, color #FDB99B, ALL CAPS
  2. Text block (Heading 1) → paste H1 (Enter between sentences) → 72px Montserrat ExtraBold, white, line-height 1.05, letter-spacing -0.025em
  3. Text block (Paragraph) → paste subhead → 19px Montserrat Regular, white at 88% opacity, max-width 680px
  4. Button Group block → two buttons:
    • Primary: Book a free consult, solid lavender #CF8BF3, white text
    • Secondary: Meet our therapists, transparent background + 1.5px white border + white text, links to /team

Step 7 — Lock fonts in Site Styles

Path: Site Styles (paint roller icon) → Fonts.

  • Headings: Montserrat 700–800
  • Paragraph: Montserrat 400
  • Buttons: Montserrat 600, letter-spacing 0.5px

Step 8 — Mobile pass

Switch to mobile view (phone icon, top of editor). Verify:

  • H1 stacks across two lines
  • Subhead wraps without orphan words
  • Buttons stack vertically (acceptable)
  • Eyebrow not cut off — reduce letter-spacing if needed
  • Photo focal point still shows the sunrise

Step 9 — Save, preview, publish

  • Save (top right)
  • Preview in a new tab — check on real desktop + real phone
  • Scroll past the hero to confirm header becomes solid and readable

5. Sunrise photo guidance

If Kevin hasn't provided a photo, use Squarespace's built-in Unsplash search.

Search queryWhat to look for
sunrise mountainsPink/orange sky with mountain silhouette. Most cinematic option.
sunrise sky pink purplePure-sky shots, no horizon. Abstract color study.
sunrise calm waterSky reflected in still water. Quieter, doubled color.
golden hour windowWarm interior light. Less literal "sunrise," more "feeling of."
palm sunrise pinkPink sky + palm silhouette. Matches Soulstice's brand-book reference.

Avoid

  • Photos with people. The hero is mood, not subjects.
  • Photos with strong centered subjects. Will fight the centered text.
  • Cool / blue tones. Will fight the warm brand palette.
  • Stock clichés. No coffee cups with steam, no alarm clocks, no laptop on a couch.
